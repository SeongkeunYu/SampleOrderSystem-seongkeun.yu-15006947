# [요구사항 명세] 모니터링 기능 (Monitoring Functional Spec)

## 1. 개요
본 시스템은 주문의 생애주기와 시료 재고 상태를 실시간으로 추적하여 관리자에게 시각적 대시보드를 제공해야 한다. 모니터링은 **주문량 확인**과 **재고량 확인** 두 가지 세부 기능으로 나뉜다.

---

## 2. 세부 기능 요구사항

### 2.1. 주문량 모니터링 (Order Status Tracking)
주문 프로세스의 각 단계별 물량을 집계하여 현재 업무 부하를 파악한다.

* **상태별 집계**: 시스템 내의 모든 유효 주문을 다음 4가지 상태로 분류하여 합계를 표시한다.
    * **예약(RESERVED)**: 접수되었으나 아직 승인/거절 처리가 되지 않은 대기 건수.
    * **생산중(PRODUCING)**: 승인되었으나 재고가 부족하여 현재 생산 라인에서 공정 진행 중인 건수.
    * **확정(CONFIRMED)**: 승인 완료 및 재고 확보가 끝났으나 아직 출고되지 않은 건수.
    * **출고(RELEASE)**: 고객에게 전달 완료된 누적 건수.
* **거절 데이터 처리**: 
    * **거절(REJECTED)** 상태의 주문은 비즈니스 흐름에서 탈락한 데이터이므로 모니터링 통계 및 목록에서 **완전히 제외**한다.
* **상세 목록 조회**: 집계된 숫자 외에 각 상태별 주문의 상세 내역(고객명, 시료명, 수량)을 리스트 형태로 확인할 수 있어야 한다.

### 2.2. 재고량 모니터링 (Stock & Health Analysis)
시료별 잔여 재고를 분석하여 생산 우선순위를 판단하는 지표를 제공한다.

* **실시간 재고 표시**: 등록된 모든 시료의 명칭과 현재 보유 수량(ea)을 테이블 형태로 노출한다.
* **재고 상태 자동 판정**: 각 시료의 상태를 다음 기준에 따라 3단계로 분류하여 표시한다.
    * **여유**: 현재 재고가 주문량보다 많거나 충분하여 안정적인 상태.
    * **부족**: 접수된 주문 수량보다 재고가 적어 생산이 시급한 상태.
    * **고갈**: 재고 수량이 `0`이 되어 즉각적인 대응이 필요한 상태.
* **잔여율(%) 시각화**: 
    * 초기 적정 재고량 대비 현재 재고 비중을 백분율로 계산하여 수치화한다.
    * 재고가 고갈에 가까워질수록 관리자가 즉각 인지할 수 있도록 강조 표시(색상 등)를 적용한다.

---

## 3. 업무 규칙 (Business Rules)

* **데이터 정합성**: 모든 모니터링 수치는 주문 승인, 출고, 생산 완료 등 상태 변화가 발생하는 즉시 실시간으로 반영되어야 한다.
* **입력 제한**: 모니터링 화면은 '조회' 전용이며, 이 화면에서 직접 데이터를 수정하거나 주문 상태를 강제로 변경할 수 없다.
* **결과 부재 처리**: 등록된 시료가 없거나 주문 내역이 존재하지 않을 경우, 빈 화면 대신 "데이터가 존재하지 않습니다"라는 명시적인 안내 문구를 표시한다.

---

## 4. 사용자 인터페이스(UI) 흐름
1. **진입**: 메인 메뉴에서 `[4] 모니터링`을 선택한다.
2. **선택**: `주문량 확인`과 `재고량 확인` 중 원하는 모드를 선택한다.
3. **조회**: 선택한 모드에 따른 테이블/통계 화면을 확인한다.
4. **복귀**: 상위 메뉴 또는 메인 메뉴로 돌아갈 수 있는 경로를 항상 제공한다.
