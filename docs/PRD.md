# PRD (Product Requirements Document): 반도체 시료 생산주문관리 시스템

## 1. 프로젝트 개요 (Project Overview)

- **배경**: 가상의 반도체 회사 "S-Semi"는 엑셀과 메모장을 활용한 수동 주문 관리로 인해 주문 누락, 공정 현황 파악 오류, 재고 관리 실패 등의 문제를 겪고 있음.
- **목표**: 체계적인 시료 관리, 재고 파악 및 공정 자동화를 지원하는 콘솔 기반의 "반도체 시료 생산주문관리 시스템" 구축.

## 2. 사용자 역할 및 프로세스 (User Roles & Workflow)

시스템은 다음 세 가지 역할을 중심으로 운영됨.

1. **고객 (Customer)**: 필요한 시료를 이메일로 요청.
2. **주문 담당자 (Order Manager)**: 요청에 맞게 주문서를 작성하고 등록.
3. **생산 담당자 (Production Manager)**: 시료를 등록하고, 주문 수신 후 승인 또는 거절 처리.

## 3. 핵심 기능 명세 (Functional Requirements)

### 3.1. 메인 메뉴 및 요약 (Main Menu)

- 시스템 접속 시 시료 종수, 총 재고량, 전체 주문 건수, 생산라인 대기 현황을 요약하여 표시.
- 시료 관리, 주문 접수/승인/거절, 모니터링, 출고 처리, 생산라인 조회 메뉴 제공.

### 3.2. 시료 관리 (Sample Management)

- **시료 등록**: 시료 ID, 이름, 평균 생산시간, 수율 속성을 시스템에 추가.
- **시료 조회/검색**: 등록된 모든 시료 목록(재고 포함)을 확인하거나 이름으로 특정 시료 검색.
- **수율(Yield) 정의**: 정상적인 시료 / 총 생산 시료.

### 3.3. 주문 및 승인 프로세스 (Order & Approval)

- **주문 생성**: 시료 ID, 고객명, 주문 수량을 입력하여 `RESERVED` 상태로 등록.
- **승인 처리**: `RESERVED` 주문에 대해 재고 상황에 따라 자동 처리.
  - **재고 충분**: 즉시 `CONFIRMED` 상태로 전환.
  - **재고 부족**: 부족분만큼 생산 라인에 자동 등록 후 `PRODUCING` 상태로 전환.
- **거절 처리**: 주문을 즉시 `REJECTED` 상태로 전환.

### 3.4. 생산 라인 및 출고 (Production & Release)

- **생산 로직**: 단일 라인에서 FIFO(선입선출) 방식으로 동작.
- **실 생산량 산출 공식**: `ceil(부족분 / (수율 * 0.9))`
- **생산 완료**: 공정 완료 시 주문 상태를 `PRODUCING`에서 `CONFIRMED`로 변경.
- **출고 실행**: `CONFIRMED` 주문을 `RELEASE` 상태로 전환하여 최종 처리.

## 4. 주문 상태 정의 (Order Status)

| 상태 | 의미 |
| :--- | :--- |
| **RESERVED** | 주문 접수 |
| **REJECTED** | 주문 거절 (정상 흐름 외 상태) |
| **PRODUCING** | 주문 승인 완료 및 재고 부족으로 생산 중 |
| **CONFIRMED** | 주문 승인 완료 및 출고 대기 중 |
| **RELEASE** | 출고 완료 |
